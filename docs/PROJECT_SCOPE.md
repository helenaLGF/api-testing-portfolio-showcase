# Project Scope, Ownership and Limitations

## Project ownership

This is an independent personal project developed by Helena Le Goff.

The implementation is maintained in a separate private GitHub repository.

This public repository contains documentation written specifically for portfolio presentation.

## Independence

The project is not a copy of an employer's or client's application.

It does not include proprietary source code, credentials, internal URLs or confidential business information.

HTTP responses are simulated in the automated tests.

## What this project demonstrates

- REST API testing concepts.
- Java test automation.
- HTTP request and response validation.
- JSON payload validation.
- Isolated and repeatable tests.
- Maven build and test execution.
- JUnit test organization.
- Allure test reporting.
- GitHub Actions CI.
- Automated static report publication.

## What this project does not claim

The current implementation does not claim:

- Complete end-to-end testing against a production API.
- Full OWASP security coverage.
- Penetration testing.
- Load or performance testing.
- Ownership of GitHub-hosted infrastructure.

## Future improvements

Potential extensions include:

- Additional negative API scenarios.
- HTTP error handling tests.
- Authentication and authorization scenarios.
- Input validation tests.
- Security-focused API test cases.
- Expanded test reporting and traceability.
